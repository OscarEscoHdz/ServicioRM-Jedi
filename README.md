# Mantenimiento de equipo de cómputo Jedi's 💻🔧

Bienvenido al repositorio oficial del sitio web de **Mantenimiento de equipo de cómputo Jedi's**. Este proyecto es una Landing Page diseñada para mostrar nuestros servicios de software, reparación, ensamble y brindar un contacto rápido directo a WhatsApp.

## 🚀 Tecnologías utilizadas
El proyecto es estático, responsivo y ligero. Está construido con:
- **HTML5:** Para la estructura semántica de la página.
- **CSS3:** Para el diseño, colores y responsividad (uso de CSS Grid y Flexbox).
- **JavaScript (Vanilla):** Para la interactividad del botón de contacto.

## ⚙️ Funcionalidades Principales
1. **Catálogo de Servicios:** Se divide en tres categorías (Software, Mantenimiento y Ensambles) mostradas en tarjetas responsivas.
2. **Ubicación Integrada:** Mapa interactivo usando un Iframe de Google Maps.
3. **Botón de Contacto Inteligente:** Funcionalidad en JS documentada que redirige automáticamente a la API de WhatsApp con un mensaje pre-cargado para solicitar cotizaciones.

## 🌐 Cómo visualizar la página (GitHub Pages)
Este proyecto está diseñado para alojarse gratuitamente a través de GitHub Pages.
1. Ve a la pestaña **Settings** (Configuración) de este repositorio en GitHub.
2. En la barra lateral izquierda, haz clic en **Pages**.
3. Bajo "Build and deployment", asegúrate de que Source esté en **Deploy from a branch**.
4. Selecciona la rama `main` (o `master`) y la carpeta `/ (root)`. Haz clic en **Save**.
5. En unos minutos, la página estará disponible y verás el enlace público en la misma sección.

## 📁 Estructura del proyecto
- `index.html`: Esqueleto principal del sitio web.
- `styles.css`: Hoja de estilos con la paleta de colores del negocio (Azul oscuro/Blanco).
- `script.js`: Archivo con la lógica de redirección y manejo del DOM debidamente documentado.
